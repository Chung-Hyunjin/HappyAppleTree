# 오늘의 행복 사과나무

학생들의 이름을 사과꽃으로 불러오고, 각 꽃에 행복을 주는 말을 적어 사과로 키워보세요. 사과 뽑기 버튼을 누르면 아직 뽑히지 않은 사과 중 하나가 랜덤으로 선택되어 크게 나타나며, 나무에서 떨어져 다시 뽑히지 않습니다.

## 사용 방법
1. `index.html`을 브라우저에서 열거나 GitHub Pages로 배포합니다.
2. **엑셀에서 학생 불러오기**를 눌러 `.xlsx`, `.xls`, `.csv` 파일을 선택합니다. 첫 번째 시트의 이름 열을 읽습니다. 첫 행의 `이름`, `학생 이름`, `성명`, `name`, `student`는 제목으로 인식해 건너뜁니다.
3. 나무의 학생 꽃을 눌러 행복한 말을 입력하고 **사과꽃 피우기**를 누릅니다.
4. **사과 뽑기**를 눌러 오늘의 행복을 확인합니다. 이미 뽑힌 사과는 다시 나오지 않습니다.

학생과 메시지는 브라우저의 `localStorage`에 저장됩니다. 엑셀 파일 처리를 위해 SheetJS CDN을 사용하므로 파일을 불러올 때 인터넷 연결이 필요합니다.
